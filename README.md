# Toko Kue: Landing Page

A static landing page for a cake shop, with a hero section, *About Us* and *Menu & Pricing*. Built with plain **HTML** and **CSS** during a Google Developer Student Clubs (GDSC) Study Jam.

## Preview

Open `TokoKue.html` in a browser. No build step needed.
